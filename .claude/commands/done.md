# Finish the session
The session is about to end. Create a `.claude/sessions/<MM-DD-YYYY_HH-MM>.md` file (run a shell command to get the current date time). Use the following template:

```md
# Session summary

## Tasks completed
- bullet point list of tasks achieved in this session

## Project overview
A breif overview of the current state of the project

## Open questions and next steps
- bullet point list of work that need to be done on the short and long term

## Known issues
- bullet point list of known problems, bugs and issues
```
