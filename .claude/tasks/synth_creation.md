# Create a new synth
You will create a new synth for the environment.

## Instructions
1. Start by ingsting documentation such as `docs/llm/building-synths.md` and necessary code.
2. Ask the user to describe the synth they want to create (sound capabilities, interaction, synthesis or samples etc.). The user can also provide contextual information in files and at web urls.
3. Look through existing synths and read examples that seem similar.
4. Decide the best structural apporach for the synth in a modular synth kind of spirit, and decide with the user if this is the best approach.
5. Create the synth.
