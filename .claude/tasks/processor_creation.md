# Create a new synth
You will create a new processor for the environment.

## Instructions
1. Start by ingsting documentation such as `docs/llm/building-processors.md` and necessary code.
2. Ask the user to describe the processor they want to create (sound capabilities, interaction etc.). The user can also provide contextual information in files and at web urls.
3. Look through existing processors and read examples that seem similar.
4. Decide the best structural apporach for the synth in a modular synth kind of spirit, and decide with the user if this is the best approach.
5. Create the processor.
6. Make sure to register and udate commands, code suggestions etc.
