# NLLC documentation

- **[docs/user](user/)** — for people typing commands into the console: a tutorial and full command/object reference.
- **[docs/dev](dev/)** — for people modifying the code: architecture, source walkthrough, and tutorials for extending the system (new synths, processors, modulators, commands).
- **[docs/llm](llm/)** — concise, context-window-friendly summaries meant to be fed to an LLM (this project's own future `Ollama()` integration, or a coding assistant) instead of the full source.
